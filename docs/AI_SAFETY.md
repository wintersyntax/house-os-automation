# AI boundaries

House OS separates model-generated language from deterministic household
facts and effects. Optional wording drafts do not authorize cleaning points,
shopping state transitions, expenses, voucher deductions, identity, or external
provider writes. Public synthetic demos do not call an AI provider.

A useful response must derive from validated, permission-scoped source facts.
If facts are missing, contradictory or too old, code should reject or indicate
uncertainty rather than invent a confident state.
