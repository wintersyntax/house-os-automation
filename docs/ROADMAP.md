# Roadmap and next evidence gates (not shipped in this public edition)

- Extend normalized, read-only household snapshots to chores, member absence and maintenance records.
- Progress private Engine source/emulator foundations to separately approved and fully verified Trello write workflows. Make v3 was reported OFF on 17 October 2026 and must not be reactivated implicitly; the existing limited Butler shopping rule remains separate.
- Explore receipt interpretation with human confirmation for uncertain items and totals; an OCR guess must never automatically post expenses.
- Evaluate small proximity/optical sensors for a possible future Waste Monitor, with stale/unknown states as first-class outputs. Hardware data would need debouncing, power-budget validation, stable event identities, false-positive tests and user consent before any automation. No physical device or receiver has been built.
- Consider more natural-language interaction only after bounded tool permissions, privacy review, evaluation fixtures and explicit approval.

Private development verified a bounded Cleaning Guardian and business test cycle, not a recurring household release. A roadmap is not proof of deployment; no proposed next step is part of the current public demo.
